# Саксофония 🎷

Обучающее приложение для игры на **альт-саксофоне** (Windows 10/11): курс из 12 модулей от дыхания до импровизации, оценка игры через микрофон и ИИ-наставник «Бибоп».

- **57 уроков и 12 экзаменов:** звук и дыхание, нотная грамота, весь диапазон, ритм, тональности, артикуляция, вибрато, свинг, блюз, импровизация.
- **Оценка игры по микрофону:** ноты, интонация в центах, ритм в миллисекундах, длительности, ровность звука, «киксы», артикуляция, динамика, вибрато, импровизация.
- **ИИ-наставник** через OpenRouter: разбор каждой попытки, чат, недельный отчёт.
- **Игровой формат:** уровни, звёзды, комбо, достижения, задания дня, серии; 6 цветовых тем.
- **Инструменты:** тюнер, метроном, бурдон, аппликатуры, аккомпанемент в 7 стилях, импорт MusicXML/MIDI, свои уроки.

📘 [Руководство пользователя](docs/GUIDE.md) · 📋 [Техническое задание](docs/SPEC.md)

## Установка

Скачайте `Saxophonia-Setup-<версия>.exe` из последнего релиза на вкладке **Releases** и запустите. Свежие сборки также доступны в **Actions → Windows build → Artifacts**. Подробности — в [руководстве](docs/GUIDE.md).

## Разработка

```bash
npm install            # зависимости
npm run dev            # веб-версия на http://localhost:5173 (для разработки)
npm test               # модульные тесты (анализ звука, оценка, курс, импорт)
npm run typecheck      # проверка типов
npm run start          # запуск в Electron
npm run dist:win       # установщик для Windows (лучше на Windows или в CI)
```

Сквозной тест в Chromium (запись саксофона подаётся как микрофон):

```bash
npm run build:web && npx vite preview --port 4173 &
ffmpeg -i public/samples/sax/D4.mp3 -ac 1 -ar 48000 /tmp/b4.wav
node e2e/run.mjs http://localhost:4173/ /tmp/b4.wav
```

### Структура

| Папка | Что внутри |
|---|---|
| `electron/` | главный процесс: окно, микрофон, ключ OpenRouter, запросы к ИИ |
| `src/audio/` | анализ звука (YIN, сегментация), сэмплер, аккомпанемент, синтез |
| `src/music/` | ноты, транспонирование, аппликатуры, теория, ABC, импорт |
| `src/practice/` | типы упражнений и оценщики |
| `src/content/` | курс: 12 модулей |
| `src/ai/` | наставник Бибоп (OpenRouter) |
| `src/ui/` | интерфейс: страницы, упражнения, нотная графика, графики |
| `tests/`, `e2e/` | модульные и сквозные тесты |
